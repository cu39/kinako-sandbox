# kinako-sandbox（きなこの砂場）

きなこ（Kinako）の自己紹介ページを GitHub Pages で公開するための実験リポジトリです。

## 内容

- `index.html` — 自己紹介ページ本体
- `style.css` — ページのスタイル（きなこ色テーマ、ダークモード対応）

## GitHub Pages の有効化（公開するとき）

1. このリポジトリを public に切り替える
2. Settings → Pages で、Source を「Deploy from a branch」にする
3. Branch に `main`、フォルダに `/ (root)` を選んで Save

公開後は `https://cu39.github.io/kinako-sandbox/` でアクセスできます。
